# 核心頁面重新設計

本文件組合針對 Public Homepage、會員 Dashboard、Admin Overview 的現況分析與實作規格。目的不是立即改寫 UI，而是讓設計與 Coding Agent 依同一份產品事實工作。

## 文件導覽

- `current-state-analysis.md`：目前路由、資料流、功能與已知問題。
- `homepage-spec.md`：公開首頁資訊架構與互動規格。
- `dashboard-spec.md`：會員入口規格。
- `admin-overview-spec.md`：幹部管理入口規格。
- `shared-design-system.md`：共用元件、Responsive 與無障礙原則。
- `implementation-plan.md`：分階段實作、風險與驗收。
- `design-ai-handoff.md`：交給視覺設計 AI 的背景與畫面要求。

本輪只建立設計文件，不修改產品 UI、資料庫或遠端資料。
